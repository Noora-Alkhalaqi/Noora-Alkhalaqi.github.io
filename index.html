MISTI Engineering Program

AI-Based Fluid Loop Monitoring System

An AI-driven monitoring and fault-diagnosis dashboard for a fluid-loop system, built as part of the MISTI Engineering Program at BAPCO in January 2026.

Show project details Hide project details
Problem
Fluid-loop systems generate large amounts of sensor data that is time-consuming to interpret and prone to errors when detecting faults such as leaks, blockages and pump failures.
Approach
Used an Arduino to collect real-time industrial data and generate a structured dataset. Implemented decision-tree fault classification, anomaly detection and Fault Tree Analysis (FTA), and built an interactive dashboard with a chatbot to assist fault diagnosis.

projects / nyc-property-analysis

Exploratory analysis

NYC Property Analysis

An exploratory analysis of New York City property sales from September 2016 to August 2017, using Python and Pandas.

Show project details Hide project details
Problem
Give stakeholders a clear view of patterns in the NYC property market, using sales transactions from September 2016 to August 2017.
Approach
Cleaned the Kaggle NYC Property Sales dataset (84,548 rows reduced to 69,987) by handling missing and invalid values, converting data types, identifying transfer transactions and creating a building age feature. Then analyzed prices by borough, sales by neighborhood, building age, monthly activity and residential versus commercial sales.
Outcome
  • Manhattan had the highest median sale price, about $1.17 million, and the Bronx the lowest, about $405,000.
  • Flushing-North had the most sales of any neighborhood analyzed, with 2,170 transactions.
  • June 2017 was the busiest month, with 5,955 transactions.
  • Residential-only sales (38,791) far outnumbered commercial-only sales (1,287).
Tools
Python / Pandas / Data Analysis / Data Visualization / Jupyter Notebook

projects / olist-shipping-evaluation

Operations analysis

Olist Shipping Company Evaluation

An evaluation of the shipping company used by Olist, a Brazilian e-commerce marketplace, covering delivery timeliness, freight cost, reliability and service quality.

Show project details Hide project details
Problem
Determine whether Olist's shipping partner is performing effectively in delivery timeliness, freight cost, reliability and service quality.
Approach
Cleaned and merged the Olist datasets (orders, customers, sellers, products, reviews, order items and geolocation) with Python. Analyzed delivery delays, freight-to-price ratios, performance by state and in-state versus out-of-state deliveries, and how delivery performance relates to customer satisfaction, cancellations and complaints.
Outcome
  • 93.22% of orders were delivered on time and 6.78% were delayed.
  • Average customer satisfaction was 4.09 out of 5.
  • The freight-to-price ratio was 32%, and freight generally rose with product weight and delivery distance.
  • Recommended keeping the current shipping partner, monitoring performance, and building a machine-learning model that predicts whether an order will be delivered on time or late.
Tools
Python / Pandas / NumPy / Matplotlib / Seaborn / Geopy / Jupyter Notebook
